# บอร์ดติดตามงานทีม

เว็บแอปมอบหมายและติดตามงานของทีม ทุกคนในรายชื่อทีมเข้าใช้ผ่านลิงก์เดียว ล็อกอินด้วยอีเมล (ไม่ต้องตั้งรหัสผ่าน) และแก้ไขข้อมูลได้พร้อมกันแบบเรียลไทม์

**ความสามารถ**
- มอบหมายงาน: วันที่มอบหมาย, วันที่คาดว่าจะแล้วเสร็จ, งบประมาณ, อ้างอิงแผนวิสาหกิจ
- แบ่งงานเป็นเฟส/งานย่อย มีวันเสร็จของแต่ละเฟส และน้ำหนักรวมกันได้ 100%
- รายงานความก้าวหน้าแบบตาราง: วันที่รายงาน, %, รายละเอียด, ปัญหา/อุปสรรค, เอกสารแนบ (Word, Excel, PDF ฯลฯ)
- แจ้งเตือนในแอป และส่งอีเมลแจ้งเตือนอัตโนมัติทุกเช้า 08:00 น.
- มุมมอง บอร์ด / รายการ / รายงาน / ทีม

**ส่วนประกอบ**

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (ไม่ต้อง build) |
| `config.js` | ค่าการเชื่อมต่อ Supabase |
| `supabase/schema.sql` | ตารางข้อมูล สิทธิ์การเข้าถึง และที่เก็บไฟล์แนบ |
| `scripts/send-reminders.mjs` | สคริปต์ส่งอีเมลแจ้งเตือน |
| `.github/workflows/reminders.yml` | ตั้งเวลาให้สคริปต์ทำงานทุกวัน |

---

## ขั้นที่ 1: สร้างฐานข้อมูล Supabase (ฟรี)

1. สมัครที่ https://supabase.com แล้วกด **New project** เลือก Region เป็น Singapore
2. ไปที่ **SQL Editor > New query** วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมด แล้วกด **Run**
3. ไปที่ **Project Settings > API** คัดลอก **Project URL** และ **anon public key** ไปใส่ใน `config.js`
4. ไปที่ **Authentication > URL Configuration** ตั้ง **Site URL** เป็นลิงก์ของแอป (ได้จากขั้นที่ 2) และเพิ่มลิงก์เดียวกันใน **Redirect URLs**

> อีเมลล็อกอินที่ Supabase ส่งให้ฟรีมีโควตาจำกัดต่อชั่วโมง ถ้าทีมใหญ่ ให้ตั้ง SMTP ของตัวเองที่ **Authentication > Emails > SMTP Settings** (ใช้ค่าเดียวกับขั้นที่ 3 ได้)
>
> โปรเจกต์ฟรีของ Supabase จะหยุดชั่วคราวถ้าไม่มีการใช้งาน 7 วัน กดเปิดคืนได้ในหน้า Dashboard (การส่งอีเมลแจ้งเตือนทุกวันช่วยให้โปรเจกต์ไม่หยุด)

## ขั้นที่ 2: เปิดเว็บด้วย GitHub Pages

1. นำไฟล์ทั้งหมดขึ้น GitHub repo (สาธารณะ ถ้าใช้ GitHub แบบฟรี)
2. ไปที่ **Settings > Pages** เลือก **Deploy from a branch**, branch `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
3. รอสักครู่ จะได้ลิงก์ เช่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` นำลิงก์นี้ไปใส่ใน Supabase ตามขั้นที่ 1 ข้อ 4

> ถ้าต้องการให้ repo เป็นแบบส่วนตัว ใช้ Netlify, Vercel หรือ Cloudflare Pages แทนได้ (ฟรี) โดยเลือก repo นี้และไม่ต้องตั้ง build command

## ขั้นที่ 3: ตั้งค่าอีเมลแจ้งเตือนอัตโนมัติ

ใช้ Gmail ส่งได้ โดยต้องเปิดการยืนยันตัวตน 2 ขั้นตอน แล้วสร้าง **App password** ที่ https://myaccount.google.com/apppasswords

ใน GitHub repo ไปที่ **Settings > Secrets and variables > Actions** แล้วเพิ่ม:

| Secret | ค่า |
|---|---|
| `SUPABASE_URL` | Project URL จาก Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | **service_role** key จาก Project Settings > API (ห้ามใส่ใน config.js) |
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | อีเมล Gmail ที่ใช้ส่ง |
| `SMTP_PASS` | App password 16 หลัก |
| `MAIL_FROM` | (ไม่บังคับ) เช่น `บอร์ดงานทีม <you@gmail.com>` |

และเพิ่ม **Variable** ชื่อ `APP_URL` เป็นลิงก์ของแอป เพื่อแนบในอีเมล

**ทดสอบ:** ไปที่แท็บ **Actions > Daily email reminders > Run workflow** ค่าเริ่มต้น `dry_run = 1` จะแสดงเนื้อหาอีเมลใน log โดยไม่ส่งจริง ถ้าถูกต้องแล้ว ระบบจะส่งจริงทุกวันเวลา 08:00 น. ตามที่ตั้งไว้

ระบบจะส่งอีเมลหนึ่งฉบับต่อคน รวมงานและเฟสที่ยังไม่เสร็จซึ่งเกินกำหนดหรือจะครบกำหนดภายในจำนวนวันที่ตั้งไว้ในแอป (ช่อง "แจ้งล่วงหน้า")

## ขั้นที่ 4: เริ่มใช้งาน

1. เปิดลิงก์แอป ใส่อีเมลของคุณ แล้วกดลิงก์ในอีเมลเพื่อเข้าระบบ
2. ไปที่แท็บ **ทีม** เพิ่ม **ตัวคุณเองเป็นสมาชิกคนแรก** (ช่องอีเมลจะเติมอีเมลที่ล็อกอินไว้ให้) แล้วเพิ่มสมาชิกคนอื่นพร้อมอีเมล
3. ส่งลิงก์ให้ทีม ทุกคนล็อกอินด้วยอีเมลที่อยู่ในรายชื่อได้ทันที

**สิทธิ์การเข้าถึง:** เฉพาะอีเมลที่อยู่ในรายชื่อทีมเท่านั้นที่ดูและแก้ไขข้อมูลได้ ถ้าลบใครออกจากรายชื่อ คนนั้นจะเข้าไม่ได้อีก (ก่อนมีสมาชิกคนแรก ใครก็ตามที่ล็อกอินจะตั้งค่าทีมได้ จึงควรเพิ่มตัวเองทันทีหลังติดตั้ง)

ถ้ายังไม่ได้ใส่ค่าใน `config.js` แอปจะเปิดเป็นโหมดทดลองที่เก็บข้อมูลในเบราว์เซอร์อย่างเดียว
